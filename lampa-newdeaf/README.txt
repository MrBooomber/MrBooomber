NewDeaf для Lampa — версія 1.0.0

Що входить
newdeaf.js — розширення Lampa, сумісний синтаксис ES5.
test.cjs — локальні перевірки реєстрації, парсерів і обмежень URL.

Можливості
• Пункт NewDeaf у лівому меню.
• Новинки, фільми, серіали, мультфільми та аніме у списках.
• Пошук і перехід на наступну сторінку категорії.
• «Знайти в NewDeaf» у контекстному меню картки Lampa.
• Вибір вебплеєра зі сторінки та відкриття у модальному вікні.
• Запасне відкриття сторінки через браузер пристрою.
• Зміна домену NewDeaf у налаштуваннях без перевстановлення плагіна.

Встановлення
1. Адреса встановлення через CDN публічного GitHub репозиторію:
   https://cdn.jsdelivr.net/gh/MrBooomber/MrBooomber@main/lampa-newdeaf/newdeaf.js
2. Вихідний код:
   https://github.com/MrBooomber/MrBooomber/tree/main/lampa-newdeaf
3. У Lampa відкрийте Налаштування → Розширення → Додати плагін.
4. Вставте HTTPS адресу встановлення з пункту 1 й перезапустіть Lampa.
5. Відкрийте NewDeaf у лівому меню.

CDN кешує файл; оновлення гілки main можуть з’являтися із затримкою.
Локальний шлях до файла не підійде для встановлення на іншому телевізорі.

Обмеження відтворення
NewDeaf на перевірених сторінках віддає iframe сторонніх провайдерів,
а не відкриті прямі HLS/MP4 потоки. Тому відтворення позначено як
експериментальне: це вебплеєр із субтитрами провайдера, а не Lampa.Player.
Вибір серій, доріжок та субтитрів виконується всередині плеєра провайдера.
Керування пультом усередині стороннього iframe може бути обмежене;
на деяких пристроях знадобиться миша або відкриття сторінки у браузері.
Повернення з плеєра: кнопка «Закрити плеєр» або Back, якщо його отримує Lampa.
Якщо iframe перехопив Back, скористайтеся системною кнопкою повернення.

Під час перевірки один провайдер повернув «контент не знайдено».
Плагін не усуває обмеження доступу, оплату, авторизацію чи DRM і не
гарантує наявність конкретного фільму або серіалу. На реальному телевізорі
й у вашій версії Lampa відтворення ще не перевірене.

Мережа і приватність
Каталог завантажується напряму з указаного NewDeaf. Перевірений сайт
віддавав Access-Control-Allow-Origin: *. Якщо власник сайту змінить CORS
або HTML, можуть знадобитися правки плагіна.
Для роботи пошук і вибрані сторінки передаються NewDeaf; під час запуску
плеєра пристрій звертається до стороннього відеопровайдера. Паролі плагін
не запитує, власної телеметрії немає. Скрипти з HTML каталогу не виконуються.
Плеєри запускаються в обмеженому iframe без дозволу відкривати popup
або перенаправляти головне вікно. Це може обмежувати деякі плеєри.
Токени плеєра не зашиті: адреси читаються з поточної сторінки.

Початковий домен
https://21oct.newdeaf.co
Якщо дзеркало зміниться, Налаштування → NewDeaf → Домен NewDeaf.
Дозволені лише HTTPS newdeaf.co та один його піддомен.

Перевірка
node --check newdeaf.js
node test.cjs
Ці тести не замінюють перевірку пульта, CORS і відео на вашому пристрої.
